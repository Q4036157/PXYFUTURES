智能期货使用说明
================

一、第一次使用
1. 把“智能期货.exe”和 README.txt 放到一个固定文件夹，例如桌面上的“智能期货”。
2. 双击“智能期货.exe”。黑色窗口是实时日志窗口，请不要关闭。
3. 稍等片刻，软件会自动打开浏览器。
4. 首次打开时设置一个至少 6 位的访问密码，然后使用该密码登录。
5. 点击右上角“天勤账号”，填写天勤账号和密码。
6. 添加需要监控的期货合约和周期。

二、以后每天使用
1. 双击“智能期货.exe”。
2. 保持黑色日志窗口开启。
3. 使用完毕后关闭黑色日志窗口即可退出软件。

三、数据和日志
- 软件会在 EXE 旁自动建立 data 文件夹。
- 合约配置、K线缓存、备注和账号配置都保存在 data 文件夹。
- 运行日志位于 data\logs\pxyfutures.log。
- 更换新版 EXE 时，请保留原来的 data 文件夹。

四、常见问题
- 浏览器没有自动打开：查看日志窗口中的“软件地址”，复制到浏览器打开。
- 出现启动失败：不要立即关闭窗口，拍下完整错误日志发给技术人员。
- 天勤维护或网络中断：软件会优先显示此前保存的本地缓存；联网后自动更新。
- Windows 弹出安全提示：确认文件来源是你的服务商后，选择“更多信息”-“仍要运行”。
