智能期货客户版使用说明
======================

一、运行环境

- 支持 Windows 10/11 64 位系统。
- 无需安装 Python、Node.js 或数据库。
- 行情更新需要电脑联网，并需要可用的天勤账号。
- 软件只监听本机 127.0.0.1，不会向局域网或公网开放端口。

二、首次使用

1. 把“智能期货.exe”放在电脑任意目录，双击运行。
2. 软件在后台静默启动，服务就绪后会自动打开默认浏览器。
3. 客户版使用本机身份，无需登录 PXYLH，也没有额外的软件密码。
4. 点击右上角“天勤账号”，填写天勤用户名和密码。
   软件会先向天勤真实验证；验证失败时不会保存错误账号。
5. 添加需要监测的自选合约及周期。

三、日常使用与退出

- 再次双击 EXE 会打开已经运行的智能期货，不会重复启动后台。
- 关闭浏览器页面不会退出软件；需要重新打开时，双击 EXE 或使用系统托盘菜单。
- 完全退出：在 Windows 右下角系统托盘找到“智能期货”，右键选择“退出软件”。
- 更新、移动或删除 EXE 前必须先从托盘退出；运行中不要覆盖正在使用的 EXE。

四、本地数据

- 配置、行情缓存和日志保存在：
  %LOCALAPPDATA%\PXYFUTURES\data
- 更换 EXE 位置或升级软件不会丢失数据。
- 如需迁移到另一台电脑，可在软件完全退出后复制上述 data 目录。

五、常见情况

- 未自动打开浏览器：再次双击 EXE，或从系统托盘选择“打开智能期货”。
- 看不到托盘图标：点击 Windows 右下角“显示隐藏的图标”。
- 天勤维护或网络中断：软件优先显示已有本地缓存，联网后继续更新。
- Windows SmartScreen 首次拦截：点击“更多信息”，确认文件名称后选择“仍要运行”。
- 启动失败日志位于：
  %LOCALAPPDATA%\PXYFUTURES\data\logs
- 最近一次脱敏认证状态位于：
  %LOCALAPPDATA%\PXYFUTURES\data\user_data\tq_auth_status.json
